Getting Started

The zkML Agent Marketplace API provides endpoints for verifying ONNX models with JOLT-Atlas zkML proofs and managing a public marketplace of verified AI agents.

Base URL: http://localhost:9002

Content-Type: application/json or multipart/form-data

Authentication: Not required for MVP (planned for future releases)

Verification API

Verify ONNX models with cryptographic zkML proofs using JOLT-Atlas proof system.

POST /verify-onnx-agent

Upload an ONNX model and generate a zkML verification certificate with JOLT-Atlas proofs.

Request Parameters

Parameter Type Required Description
onnxModel File Required ONNX model file (.onnx format, max 50MB)
agentName String Required Display name for the agent
agentDescription String Optional Description of the agent's functionality
testInputs JSON Array Required Array of test input arrays: [[1,2,3], [4,5,6]]

Response

{ "success": true, "verificationId": "0xabc123...", "modelHash": "0xdef456...", "proofHash": "0x789abc...", "proofSystem": "JOLT-Atlas", "testCasesPassed": 2, "testResults": [ { "testCase": 1, "input": [1, 2, 3], "output": [0.234, 0.766], "inferenceTimeMs": 12 } ], "metadata": { "modelSizeMB": 1.8, "estimatedParams": 256 }, "performance": { "localInferenceMs": 12, "estimatedProofSec": 0.6 }, "simulated": false, "verifiedAt": "2025-10-04T12:00:00Z" }
GET /verification/:verificationId

Retrieve a verification credential by ID.

Response

{ "success": true, "verification": { "verificationId": "0xabc123...", "modelHash": "0xdef456...", "agentName": "FraudDetector Pro", "proofSystem": "JOLT-Atlas", "verifiedAt": "2025-10-04T12:00:00Z" } }

Marketplace API

Browse, search, and manage verified agents in the public marketplace.

POST /agents/register

Register a verified agent to the public marketplace.

Request Body

{ "verificationId": "0xabc123...", "makePublic": true }

Response

{ "success": true, "message": "Agent registered to marketplace", "modelHash": "0xdef456...", "marketplaceUrl": "http://localhost:9003/agent.html?hash=0xdef456..." }
GET /agents

List all verified agents with pagination, search, and sorting.

Query Parameters

Parameter Type Default Description
limit Number 10 Number of results to return
offset Number 0 Pagination offset
search String - Search by name or description
sortBy String verifiedAt Sort field: verifiedAt, agentName, usageCount
order String desc Sort order: asc or desc

Response

{ "success": true, "agents": [ { "modelHash": "0xdef456...", "agentName": "FraudDetector Pro", "agentDescription": "AI fraud detection agent", "proofSystem": "JOLT-Atlas", "testCasesPassed": 10, "verifiedAt": "2025-10-04T12:00:00Z", "usageCount": 42 } ], "total": 1, "hasMore": false }
GET /agents/:modelHash

Get detailed information about a specific agent including full verification certificate.

Response

{ "success": true, "agent": { "modelHash": "0xdef456...", "agentName": "FraudDetector Pro", "agentDescription": "AI fraud detection agent", "proofHash": "0x789abc...", "proofSystem": "JOLT-Atlas", "testCasesPassed": 10, "testResults": [...], "metadata": {...}, "performance": {...}, "verifiedAt": "2025-10-04T12:00:00Z", "usageCount": 42 } }
GET /agents/:modelHash/verify

Verify an agent's certificate (for agent-to-agent composition). Returns verification status without modifying any state.

Response

{ "success": true, "verified": true, "modelHash": "0xdef456...", "proofHash": "0x789abc...", "proofSystem": "JOLT-Atlas", "verifiedAt": "2025-10-04T12:00:00Z" }
GET /marketplace/stats

Get marketplace statistics.

Response

{ "success": true, "stats": { "totalAgents": 15, "totalVerifications": 150, "totalUsage": 1250 } }

Code Examples

cURL - Verify an ONNX Agent

curl -X POST http://localhost:9002/verify-onnx-agent \ -F "onnxModel=@model.onnx" \ -F "agentName=FraudDetector Pro" \ -F "agentDescription=AI fraud detection agent" \ -F 'testInputs=[[1,2,3],[4,5,6]]'

JavaScript - Register Agent to Marketplace

const response = await fetch('http://localhost:9002/agents/register', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ verificationId: '0xabc123...', makePublic: true }) }); const result = await response.json(); console.log('Agent registered:', result.marketplaceUrl);

JavaScript - Agent-to-Agent Verification

// Agent A wants to use Agent B - verify B's certificate first const response = await fetch(`http://localhost:9002/agents/${agentBHash}/verify`); const { verified, proofHash, modelHash } = await response.json(); if (verified) { // Safe to call Agent B - zkML proof guarantees behavior const result = await callAgentB(input); } else { throw new Error('Agent B not verified - cannot trust'); }

Python - List Marketplace Agents

import requests response = requests.get( 'http://localhost:9002/agents', params={ 'limit': 10, 'search': 'fraud', 'sortBy': 'usageCount', 'order': 'desc' } ) data = response.json() for agent in data['agents']: print(f"{agent['agentName']}: {agent['usageCount']} uses")

Error Handling

All errors follow a consistent format with HTTP status codes and descriptive messages.

Error Response Format

{ "success": false, "error": "Error message description", "code": "ERROR_CODE" }

Common Error Codes

Status Code Error Description
400 Bad Request Missing or invalid parameters
404 Not Found Agent or verification not found
413 Payload Too Large ONNX model exceeds 50MB limit
500 Internal Server Error Proof generation or verification failed
