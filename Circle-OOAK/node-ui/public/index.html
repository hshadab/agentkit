🔍 Architecture Overview

        
    
          
  • User → AI Agent: Transaction request flows through Circle OOAK agent framework
    • 
          
  • ONNX Neural Network: Real ML model (4→8→4→1 architecture) performs authorization inference computation
    • 
          
  • @secure_tool Decorator: Circle's hook-based approval system with 5 sequential steps:
    • 
          
  •   1. before_invoke_tool() - Authorization: ONNX decision enforced as policy (approve/deny based on risk)
    • 
          
  •   2. before_invoke_tool() - zkML Proof: JOLT-Atlas Rust binary proves ML inference executed correctly (~600ms)
    • 
          
  •   3. before_invoke_tool() - On-Chain: Groth16 zk-SNARK verified on Ethereum Sepolia (0x1279...) for permanent audit
    • 
          
  •   4. send_usdc: Circle Execute USDC transfer on Base Sepolia if all checks pass
    • 
          
  •   5. after_invoke_tool(): Post-execution validation to verify transaction success and log results
    • 
          
  • Workflow Manager: Evaluates all @secure_tool results and makes final authorization decision
    • 
          
  • USDC Payment: Circle USDC stablecoin (Circle DCW API or direct ERC-20)
