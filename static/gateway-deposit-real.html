How Gateway Deposit Works

Circle Gateway uses a "burn and mint" mechanism. You'll burn USDC on Sepolia, and it becomes available as spendable balance in the Gateway system for cross-chain transfers.

  • 2 Approve USDC for Gateway
  • 3 Deposit USDC to Gateway
